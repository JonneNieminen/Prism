# Prism — agent notes

Local AI stem separation desktop app. Tauri 2 + React/TS/Vite/Tailwind 4/Motion; Rust core with ONNX Runtime (no Python at runtime).

## Layout
- `crates/prism-core` — all logic, no Tauri deps: `audio` (symphonia decode, rubato resample, WAV cache), `dsp` (torch-compatible STFT), `manifest` (model.json schema + strict validation), `separator` (the `Separator` trait + `run`), `adapters/{demucs,mdx}` (architecture adapters), `runtime` (ORT sessions, Core ML/CPU), `models` (install/import/remove), `catalog`, `library`, `export`, `settings`.
- `crates/prism-cli` — headless harness: `prism separate|compare|validate`.
- `src-tauri` — thin commands (`lib.rs`), background jobs + events (`jobs.rs`), state (`state.rs`).
- `src` — UI. `lib/ipc.ts` is the only backend boundary (`lib/mock.ts` = browser stand-in). `bindings/` is generated by ts-rs — never edit by hand.
- `models/htdemucs/` bundled model (weights git-ignored, `npm run fetch-models`). `catalog/index.json` = default catalog (regenerate with `scripts/make-catalog.py`).
- `tools/export` — dev-only pinned Python env that converts Demucs to ONNX and checks parity.

## Commands (prefix cargo with `PATH=/opt/homebrew/opt/rustup/bin:$PATH` on this Mac)
- UI only, mock backend: `npm run dev` · typecheck: `npm run typecheck`
- App: `npx tauri dev` · release `.app/.dmg`: `npx tauri build`
- Rust tests (also regenerates `src/bindings`): `cargo test -p prism-core` (e2e test needs weights; `PRISM_TEST_AUDIO=song.mp3` uses real music)
- Parity: `cargo build -p prism-cli && ./target/debug/prism separate x.wav --model models/htdemucs --shifts 0 --overlap 0.25 --cpu`, then `prism compare`.

## Rules
- Nothing may special-case a model: stems, colors and names come from `model.json`. New architecture = new file in `adapters/` + entries in `adapters/mod.rs` (see its doc comment) + a parity test.
- Weights: ONNX only. Never load pickled checkpoints (`.pt/.th/.ckpt`); catalog downloads must be https + sha256-verified before install.
- `ort` sessions must keep `with_auto_device(PreferCPU)` — the default policy auto-registers Core ML in a mode that yields NaNs for Demucs.
- UI colors only via CSS variables in `src/styles/tokens.css` (dark + light). Stem colors via `lib/colors.ts`.
- Heavy work never on the UI thread: Rust work runs in `blocking(...)`/job threads; playback updates are imperative (rAF), not React state.
- Changing a Rust type exposed to the UI: rerun `cargo test -p prism-core` and commit `src/bindings`.
