Prism {{VERSION}} for macOS ({{ARCH}})
====================================

1. Drag Prism onto the Applications folder in this window.

2. This build isn't notarized by Apple yet, so macOS blocks the first launch
   ("Prism is damaged" or "can't be opened"). Open Terminal, paste this line
   and press Return:

   xattr -dr com.apple.quarantine /Applications/Prism.app

3. Open Prism from Applications or Launchpad. You only need step 2 once.

What the command does: it removes the "downloaded from the internet" flag that
macOS puts on files from a browser, so Gatekeeper stops blocking this copy.
It changes nothing else.

Prefer not to use Terminal? Open Prism once, then go to System Settings >
Privacy & Security, scroll down and click "Open Anyway" next to Prism.
